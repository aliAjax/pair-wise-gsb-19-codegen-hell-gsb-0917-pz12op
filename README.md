# hxwl-05 水族箱水质记录器

多鱼缸水质连续监测、状态自动判定、异常停喂提醒与换水周期管理

## 技术栈

React + Vite + TypeScript + CSS（数据保存在浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **自带示例**：首次打开自动生成草缸A、海缸B、繁殖缸C及示例监测 / 换水历史；其中繁殖缸C最近两次监测均异常且已过换水日，用于演示提醒。
- **一次填齐的监测录入**：新增普通监测必须同时填写 pH、氨氮（ppm）、硝酸盐（ppm）、温度（°C），缺一项不能保存。
- **状态自动判定**：按鱼缸类型（草缸 / 海缸 / 繁殖缸）各自的阈值，将每项指标判为稳定 / 关注 / 异常，记录状态取最差项，界面不提供也不允许手动选择状态；填写时即显示单项与整体判定预览。
- **连续异常提醒**：某缸最近连续两次（及以上）监测异常时，缸详情顶部出现“先停止投喂、尽快换水”横幅；复测恢复正常后自动消失。
- **换水周期**：换水记录以换水时刻 + 本次设定的换水周期计算“距下次换水天数”，可显示今日到期或已逾期；普通监测不会重置该天数，只有新的换水记录才会重算。
- **撤销与回算**：任意监测或换水记录均可撤销，状态、连续异常提醒和换水天数立即按剩余历史重新推导。
- **持久化**：所有数据写入 localStorage，刷新 / 重开浏览器后保留；右上角“恢复示例数据”可一键重置。
